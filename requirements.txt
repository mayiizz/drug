# MODEL STACK USED IN THIS PROJECT
# ----------------------------------------------------
# 1) Molecular generation prior / policy:
#    - REINVENT-style SMILES LSTM (PyTorch)
#    - Prior checkpoints: checkpoints/prior_best_validity.pt / prior_latest.pt
#    - IMPORTANT: REINVENT here is an INTERNAL implementation under:
#      models/generation/reinvent4/*.py  (not a pip package named "reinvent")
#
# 2) Embedding / semantic dedup:
#    - HuggingFace model: seyonec/ChemBERTa-zinc-base-v1
#
# 3) Binding prefilter:
#    - DeepPurpose DTI model (CNN_CNN_BindingDB)
#
# 4) Research agent LLM:
#    - LangGraph + LangChain + Groq (ChatGroq)
#    - Default model in code: llama-3.3-70b-versatile
#
# 5) Docking:
#    - AutoDock Vina executable (external binary, not pip)
#    - OpenBabel / MGLTools for ligand/receptor prep (external tools)
#
# 6) Frontend UI stack (separate, Node ecosystem):
#    - Next.js 16, React 19, TypeScript 5, TailwindCSS 4, Framer Motion
#    - Install via: npm install (inside frontend/)
